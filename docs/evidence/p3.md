## Method

- Rule 1 (`prover/src/chain.ts`): every run pins one block. It reads `circuitInfo` and
  `netlist` of each circuit, and of every REF target, at that block. It then checks each
  keccak-256 against the hash recorded at tape-out, and stops on any difference.
- Facts (`prover/src/fact.ts`): Verilog is exported from those bytes (`prover/src/export.ts`).
  Each fact is a question "is there an input that breaks it?", asked of two tools:
  - ABC `iprove`;
  - Yosys `sat -prove`.
  If the tools disagree, the run stops.
- A third tool, added the same day for facts the first two left open: Yosys `write_smt2`
  writes the question at word level as SMT-LIB 2, and Bitwuzla 0.9.1 (same OSS CAD Suite)
  answers. It shares only the Verilog reader with the other two. Its invocation follows the
  help text of both tools, read on the host (`docs/evidence/p3/tools/smt-help.log`).
- Replay: a counterexample is replayed in the simulator and with `eval` on chain at the
  pinned block before it is reported.
- Mutants: every fact that holds has a mutant of the rule that must come back "fails".
  Otherwise the run stops, because the question could not tell a broken rule.
- Tests (task `p3-prover-test`, 2026-11-24):
  - a true fact holds in both tools;
  - a broken fact fails at the hand-worked input (x = 49) in both tools;
  - a forced 1 s limit gives "undecided";
  - the trap finder returns the two hand-worked ranges and proves none is left.
  Rerun after the third tool was added (`docs/evidence/p3/tools/prover-test.log`): 5 of 5
  pass. The new tool proves the true fact, finds x = 49 for the broken one, finds a planted
  break at x = 7, and gives "undecided" at 1 s on a 32-bit multiplier built from NAND gates.
  A word-level product could not test the limit: Bitwuzla proved the 64-bit distributive law
  at once.
  The seven export round-trip tests were skipped. They need the Yosys JSON from host-service,
  which is down.

Each link has a control that must come back "not equivalent", and every control did.

| Link | Check | Result | Control |
| --- | --- | --- | --- |
| 1 | Joined RTL `split_check_mod` against the original `split_check`, 32 bits (ABC `&cec`) | equivalent, 0.0 s | `MUTANT_VALID_OR`: not equivalent, 89.3 s |

| 2 | Circuit 7 against `m_x10000_wide` RTL | equivalent, 173.7 s | ×10001: not equivalent |

How circuit 3 was checked:

layout of circuit 3 (`a` in bits 0 to 31, `b` in bits 32 to 63), which link 3 also relies on.

### What follows

Every link holds. So circuit 8 on X Layer accepts exactly the payouts of the integer
predicate, and the six split facts of PLAN 11.1 hold for it, each proved by two solvers.

The support fact that a holder has only one accepted payout is proved by Z3 alone. That fact
matters because it makes "the payout" well defined.

`fee-is-fixed` is not covered: there is no fee circuit yet (P4).
